# OpenAll

WotLK 3.3.5a mail helper (Kemayo). Adds **Take All** and **Take Cash** on the mailbox.

## Clear empty mail

`/openall clear` toggles deleting a letter after gold and attachments are taken. COD mail is left alone. GM/store mail is deleted once it is empty. The Take All tooltip shows ON/OFF.

Setting is saved in `OpenAllDB`.
